AnimeShelf — первый кликабельный прототип.

Что уже работает:
- Главная
- Поиск по 100 тайтлам
- Карточки аниме
- Добавление в библиотеку
- Статусы
- Оценки
- «Удиви меня»
- Экран «Мой вкус»
- Данные библиотеки сохраняются локально в браузере

Для установки на iPhone как PWA index.html нужно разместить на HTTPS-хостинге.
Это прототип: обложки, реальные описания, синхронизация и умный рекомендатель — следующие этапы.
